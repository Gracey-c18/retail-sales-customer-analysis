# Retail Sales & Customer Analysis

## Project Overview

This project analyses real-world retail transaction data to identify sales trends, top-performing products, and customer purchasing patterns.

## Business Problem

Retail businesses need to understand what drives sales, which products perform best, and how customer purchasing behaviour changes over time. Without these insights, management may struggle to make informed decisions about inventory, sales strategies, and customer retention.

## Project Objectives

* Analyse monthly sales performance.
* Identify top-performing products.
* Examine customer purchasing behaviour.
* Investigate cancelled transactions and their impact on sales.
* Provide actionable, data-driven business recommendations.

## Dataset

**Source:** UCI Machine Learning Repository — Online Retail Dataset

**Period:** December 2010 to December 2011

**Format:** Excel

**Key fields:** InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID, Country.
